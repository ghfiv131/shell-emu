# Эмулятор командной оболочки UNIX (вариант 13)

## Общее описание

Консольное (CLI) приложение, имитирующее работу командной строки
UNIX-подобной ОС. Написано на Python 3 без сторонних зависимостей.

Текущее состояние: **этап 1 — REPL**. Прототип ведёт диалог с
пользователем, команды `ls` и `cd` пока являются заглушками.

## Структура репозитория

| Путь                  | Назначение                         |
|-----------------------|------------------------------------|
| `src/shell_emulator/` | исходный код эмулятора             |
| `tests/`              | модульные тесты (unittest)         |
| `run.sh`              | запуск эмулятора и тестов          |

## Функции и настройки

### Приглашение к вводу

Имеет вид `<имя VFS>:<текущий каталог>$ `, например `vfs:/$ `.

### Парсер

Строка ввода разделяется на команду и аргументы по пробельным символам.
Несколько пробелов подряд считаются одним разделителем, пустая строка
игнорируется. Кавычки и экранирование не поддерживаются.

### Команды

| Команда       | Описание                                                  |
|---------------|-----------------------------------------------------------|
| `ls [args]`   | заглушка: выводит имя команды и список аргументов         |
| `cd [args]`   | заглушка: выводит имя команды и список аргументов         |
| `exit [code]` | завершает работу с кодом `code` (по умолчанию 0)          |

Конец ввода (Ctrl+D) также завершает работу с кодом 0, Ctrl+C
сбрасывает текущую строку.

### Обработка ошибок

Сообщения об ошибках выводятся в stderr в формате
`emulator: <команда>: <описание>`:

* неизвестная команда — `command not found`;
* `exit` с нечисловым аргументом — `numeric argument required`;
* `exit` с несколькими аргументами — `too many arguments`.

После ошибки эмулятор продолжает работу.

## Сборка и запуск тестов

Сборка не требуется, нужен Python 3.8+.

```sh
./run.sh          # запуск эмулятора
./run.sh test     # запуск тестов
```

Без `run.sh`:

```sh
PYTHONPATH=src python3 -m shell_emulator
python3 -m unittest discover -s tests -v
```

## Примеры использования

```
$ ./run.sh
vfs:/$ ls
ls: args=[]
vfs:/$ ls -l /home   /tmp
ls: args=['-l', '/home', '/tmp']
vfs:/$ cd
cd: args=[]
vfs:/$ cd /usr/bin
cd: args=['/usr/bin']
vfs:/$
vfs:/$ foo bar
emulator: foo: command not found
vfs:/$ exit abc
emulator: exit: abc: numeric argument required
vfs:/$ exit 1 2
emulator: exit: too many arguments
vfs:/$ exit 3
$ echo $?
3
```
