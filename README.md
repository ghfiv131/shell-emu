# Эмулятор командной оболочки UNIX (вариант 13)

## Общее описание

Консольное (CLI) приложение, имитирующее работу командной строки
UNIX-подобной ОС. Написано на Python 3 без сторонних зависимостей.

Текущее состояние: **этап 2 — конфигурация**. Эмулятор ведёт диалог
с пользователем, принимает параметры командной строки и выполняет
стартовый скрипт. Команды `ls` и `cd` пока являются заглушками.

## Структура репозитория

| Путь                  | Назначение                         |
|-----------------------|------------------------------------|
| `src/shell_emulator/` | исходный код эмулятора             |
| `tests/`              | модульные тесты (unittest)         |
| `startup/`            | стартовые скрипты эмулятора        |
| `scripts/`            | тестовые скрипты ОС (sh)           |
| `run.sh`              | запуск эмулятора и тестов          |

## Функции и настройки

### Параметры командной строки

```
./run.sh [-h] [--vfs PATH] [--script PATH]
```

| Параметр        | Описание                                            |
|-----------------|-----------------------------------------------------|
| `--vfs PATH`    | путь к физическому расположению VFS                 |
| `--script PATH` | путь к стартовому скрипту                           |
| `-h`, `--help`  | справка                                             |

Имя VFS в приглашении — имя файла `--vfs` без расширения
(`/data/my_disk.json` → `my_disk`), без параметра — `vfs`.

При запуске выводятся отладочные значения всех параметров:

```
[debug] vfs_path    = '/data/my_disk.json'
[debug] vfs_name    = 'my_disk'
[debug] script_path = 'startup/stage2_ok.txt'
```

### Стартовый скрипт

Текстовый файл, по одной команде эмулятора в строке. Пустые строки и
строки, начинающиеся с `#`, пропускаются. Каждая команда выводится
вместе с приглашением, а затем её результат, как в диалоге с
пользователем.

* При первой ошибке выполнение останавливается, выводится сообщение
  `emulator: <скрипт>:<строка>: error in command '<команда>', script
  aborted`, эмулятор завершается с кодом 1.
* Если скрипт не удаётся открыть, эмулятор завершается с кодом 2.
* Команда `exit` в скрипте завершает эмулятор с указанным кодом.
* Если скрипт выполнен без ошибок и без `exit`, эмулятор переходит в
  интерактивный режим.

| Код | Значение                                         |
|-----|--------------------------------------------------|
| 0   | нормальное завершение (или код из `exit N`)      |
| 1   | ошибка во время выполнения стартового скрипта    |
| 2   | неверные параметры или скрипт не найден          |

### Приглашение к вводу

Имеет вид `<имя VFS>:<текущий каталог>$ `, например `vfs:/$ `.

### Парсер

Строка ввода разделяется на команду и аргументы по пробельным символам.
Несколько пробелов подряд считаются одним разделителем, пустая строка
игнорируется. Кавычки и экранирование не поддерживаются.

### Команды

| Команда       | Описание                                                  |
|---------------|-----------------------------------------------------------|
| `ls [args]`   | заглушка: выводит имя команды и список аргументов         |
| `cd [args]`   | заглушка: выводит имя команды и список аргументов         |
| `exit [code]` | завершает работу с кодом `code` (по умолчанию 0)          |

Конец ввода (Ctrl+D) также завершает работу с кодом 0, Ctrl+C
сбрасывает текущую строку.

### Обработка ошибок

Сообщения об ошибках выводятся в stderr в формате
`emulator: <команда>: <описание>`:

* неизвестная команда — `command not found`;
* `exit` с нечисловым аргументом — `numeric argument required`;
* `exit` с несколькими аргументами — `too many arguments`.

После ошибки эмулятор продолжает работу.

## Сборка и запуск тестов

Сборка не требуется, нужен Python 3.8+.

```sh
./run.sh                       # запуск эмулятора
./run.sh --vfs disk.json --script startup/stage2_ok.txt
./run.sh test                  # запуск модульных тестов
sh scripts/test_config.sh      # все комбинации параметров
sh scripts/test_script_errors.sh   # ошибки в стартовом скрипте
sh scripts/test_cli_errors.sh  # ошибки в параметрах командной строки
```

Без `run.sh`:

```sh
PYTHONPATH=src python3 -m shell_emulator
python3 -m unittest discover -s tests -v
```

## Примеры использования

```
$ ./run.sh
vfs:/$ ls
ls: args=[]
vfs:/$ ls -l /home   /tmp
ls: args=['-l', '/home', '/tmp']
vfs:/$ cd
cd: args=[]
vfs:/$ cd /usr/bin
cd: args=['/usr/bin']
vfs:/$
vfs:/$ foo bar
emulator: foo: command not found
vfs:/$ exit abc
emulator: exit: abc: numeric argument required
vfs:/$ exit 1 2
emulator: exit: too many arguments
vfs:/$ exit 3
$ echo $?
3
```

Стартовый скрипт с ошибкой:

```
$ ./run.sh --vfs /tmp/other.json --script startup/stage2_exit_error.txt
[debug] vfs_path    = '/tmp/other.json'
[debug] vfs_name    = 'other'
[debug] script_path = 'startup/stage2_exit_error.txt'
other:/$ cd /home
cd: args=['/home']
other:/$ exit not-a-number
emulator: exit: not-a-number: numeric argument required
emulator: startup/stage2_exit_error.txt:3: error in command 'exit not-a-number', script aborted
$ echo $?
1
```
