# Эмулятор командной оболочки UNIX (вариант 13)

## Общее описание

Консольное (CLI) приложение, имитирующее работу командной строки
UNIX-подобной ОС. Написано на Python 3 без сторонних зависимостей.

Реализованы этапы:

1. **REPL** — интерактивный диалог, парсер, заглушки `ls` и `cd`, `exit`.
2. **Конфигурация** — параметры `--vfs` и `--script`, отладочный вывод
   параметров, стартовый скрипт с остановкой на первой ошибке.
3. **VFS** — виртуальная файловая система загружается из JSON-файла и
   хранится только в памяти; служебные команды `vfs-info` и `vfs-tree`.

## Функции и настройки

### Параметры командной строки

```
./run.sh [-h] [--vfs PATH] [--script PATH]
```

| Параметр        | Описание                                            |
|-----------------|-----------------------------------------------------|
| `--vfs PATH`    | путь к JSON-файлу VFS (без него — пустая VFS)       |
| `--script PATH` | путь к стартовому скрипту                           |
| `-h`, `--help`  | справка                                             |

При запуске выводятся отладочные значения всех параметров и сведения о
загруженной VFS:

```
[debug] vfs_path    = 'vfs/deep.json'
[debug] vfs_name    = 'deep'
[debug] script_path = 'startup/stage3_vfs.txt'
[debug] vfs loaded: name='deep', dirs=11, files=8, size=321
```

`vfs_name` — имя, вычисленное по пути. Если в JSON задано поле `name`,
используется оно (см. строку `vfs loaded`).

### Приглашение к вводу

Имеет вид `<имя VFS>:<текущий каталог>$ `, например `deep:/$ `.

### Парсер

Строка ввода разделяется на команду и аргументы по пробельным символам.
Несколько пробелов подряд считаются одним разделителем, пустая строка
игнорируется. Кавычки и экранирование не поддерживаются.

### Команды

| Команда            | Описание                                             |
|--------------------|------------------------------------------------------|
| `ls [args]`        | заглушка: выводит имя команды и список аргументов    |
| `cd [args]`        | заглушка: выводит имя команды и список аргументов    |
| `exit [code]`      | завершает работу с кодом `code` (по умолчанию 0)     |
| `vfs-info`         | служебная: имя, источник, число каталогов и файлов   |
| `vfs-tree [path]`  | служебная: дерево каталога `path` (по умолчанию `.`) |

Пути в `vfs-tree` могут быть абсолютными и относительными, `.` и `..`
поддерживаются (`..` выше корня остаётся в корне).

Конец ввода (Ctrl+D) завершает работу с кодом 0, Ctrl+C сбрасывает
текущую строку.

### Обработка ошибок команд

Сообщения выводятся в stderr в формате `emulator: <команда>: <описание>`,
после ошибки эмулятор продолжает работу (в интерактивном режиме):

* неизвестная команда — `command not found`;
* `exit` с нечисловым аргументом — `numeric argument required`;
* лишние аргументы `exit`, `vfs-info`, `vfs-tree` — `too many arguments`;
* `vfs-tree` для несуществующего пути — `No such file or directory`;
* `vfs-tree` для файла — `Not a directory`.

### Стартовый скрипт

Текстовый файл, по одной команде эмулятора в строке. Пустые строки и
строки, начинающиеся с `#`, пропускаются. Каждая команда выводится
вместе с приглашением, а затем её результат, как в диалоге с
пользователем.

* При первой ошибке выполнение останавливается, выводится сообщение
  `emulator: <скрипт>:<строка>: error in command '<команда>', script
  aborted`, эмулятор завершается с кодом 1.
* Команда `exit` в скрипте завершает эмулятор с указанным кодом.
* Если скрипт выполнен без ошибок и без `exit`, эмулятор переходит в
  интерактивный режим.

### Формат VFS

```json
{
  "name": "my_disk",
  "root": {
    "type": "dir",
    "children": {
      "readme.txt": {"type": "file", "content": "hello\n"},
      "data.bin":   {"type": "file", "encoding": "base64",
                     "content": "AAECAw=="},
      "home":       {"type": "dir", "children": {}}
    }
  }
}
```

| Поле       | Описание                                                  |
|------------|-----------------------------------------------------------|
| `name`     | имя VFS (необязательно, по умолчанию — имя файла)         |
| `root`     | корневой каталог, обязательно `"type": "dir"`             |
| `type`     | `dir` или `file`                                          |
| `children` | объект «имя → узел» (для каталога, по умолчанию пустой)   |
| `content`  | содержимое файла (строка, по умолчанию пустая)            |
| `encoding` | `text` (по умолчанию) или `base64` для двоичных данных    |

VFS полностью загружается в память, исходный файл не распаковывается и
не изменяется. Некорректная VFS (файл не найден, неверный JSON, нет
`root`, корень — файл, неизвестный тип узла, неверный base64,
недопустимое имя `""`, `.`, `..` или имя с `/`) приводит к сообщению
`emulator: cannot load VFS: ...` и завершению с кодом 2.

### Коды возврата

| Код | Значение                                                  |
|-----|-----------------------------------------------------------|
| 0   | нормальное завершение (или код из `exit N`)               |
| 1   | ошибка во время выполнения стартового скрипта             |
| 2   | неверные параметры, скрипт не найден, VFS не загружена    |

## Сборка и запуск тестов

Сборка не требуется, нужен Python 3.8+.

```sh
./run.sh                           # интерактивный режим, пустая VFS
./run.sh --vfs vfs/deep.json       # интерактивный режим с VFS
./run.sh test                      # модульные тесты
```

Тестовые скрипты ОС:

```sh
sh scripts/test_config.sh          # этап 2: комбинации параметров
sh scripts/test_script_errors.sh   # этап 2: ошибки в стартовом скрипте
sh scripts/test_cli_errors.sh      # этап 2: ошибки параметров
sh scripts/test_vfs.sh             # этап 3: разные варианты VFS
sh scripts/test_vfs_errors.sh      # этап 3: ошибки загрузки VFS
```

Без `run.sh`:

```sh
PYTHONPATH=src python3 -m shell_emulator --vfs vfs/deep.json
python3 -m unittest discover -s tests -v
```

## Примеры использования

Интерактивный режим:

```
$ ./run.sh
[debug] vfs_path    = None
[debug] vfs_name    = 'vfs'
[debug] script_path = None
[debug] vfs loaded: name='vfs', dirs=1, files=0, size=0
vfs:/$ ls -l /home   /tmp
ls: args=['-l', '/home', '/tmp']
vfs:/$ cd /usr/bin
cd: args=['/usr/bin']
vfs:/$ foo bar
emulator: foo: command not found
vfs:/$ exit abc
emulator: exit: abc: numeric argument required
vfs:/$ exit 3
$ echo $?
3
```

Стартовый скрипт и VFS:

```
$ ./run.sh --vfs vfs/deep.json --script startup/stage3_not_dir.txt
[debug] vfs_path    = 'vfs/deep.json'
[debug] vfs_name    = 'deep'
[debug] script_path = 'startup/stage3_not_dir.txt'
[debug] vfs loaded: name='deep', dirs=11, files=8, size=321
deep:/$ vfs-tree /etc
/etc
├── hostname (9 B)
└── motd (9 B)
deep:/$ vfs-tree /etc/hostname
emulator: vfs-tree: /etc/hostname: Not a directory
emulator: startup/stage3_not_dir.txt:3: error in command 'vfs-tree /etc/hostname', script aborted
$ echo $?
1
```

    └── log/
